🪄 How a Handle gets minted

Uniqueness, price and delivery are enforced by the contracts, not by the server that builds the transaction.
STEP 1
📝
Order
The buyer locks an order at the orders contract with the Handle name and enough ADA to pay for it.
request()
STEP 2
🌳
Prove
The minter rebuilds the Handle trie, confirms its root matches the chain, and proves each name isn't taken.
prepareNewMintTransaction()
STEP 3
⚖️
Validate
On-chain: proofs must advance the root, prices and fees must be paid, names must be valid, and an allowed minter must sign.
Aiken validators
STEP 4
🎉
Deliver
The Handle (222) lands in the buyer's wallet. Its reference token (100) goes to the personalization contract.
mintNewHandles()
